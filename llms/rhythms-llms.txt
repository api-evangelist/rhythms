# Rhythms

> Rhythms is an AI operating partner for teams (built by the Ally.io / Microsoft Viva Goals team) that automates business reviews, pre-briefs, reports, and OKR/goal tracking across hundreds of connected tools. It exposes a multi-tenant REST API and supports custom MCP integrations.

## API
- [Rhythms API (OpenAPI 3.0)](https://api.rhythms.ai/openapi.json): 31 operations — documents, teams, users, labels, OKR objectives & time periods, data sources, connector & access requests, explorer views. Page-based pagination; Ransack (q) filtering; authentication required; tenant-scoped.
